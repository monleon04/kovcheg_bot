# Ковчег — обновлённая версия Discord-бота

## Запуск

1. Установить Python 3.10+ и зависимости:
   `pip install -r requirements.txt`
2. Задать переменную окружения `DISCORD_TOKEN`.
3. Запустить:
   `python bot.py`

При первом запуске или обновлении база SQLite мигрирует автоматически. Старый файл
`kovcheg.sqlite3` не удаляется.

## Как не потерять прогресс при обновлении

Игровой прогресс хранится в файле `kovcheg.sqlite3`, а не в коде бота. Поэтому
этот файл должен находиться на постоянном диске сервера и не должен удаляться при
пересборке или деплое из GitHub. Добавьте `kovcheg.sqlite3` в `.gitignore`, но
настройте для хостинга persistent volume / persistent disk с рабочей директорией
бота. Если хостинг каждый раз создаёт полностью новую файловую систему, одного
GitHub недостаточно — нужна внешняя постоянная SQLite/Postgres-база или резервная
копия базы перед обновлением.

Для постоянного диска можно задать `DATABASE_PATH`, например
`/data/kovcheg.sqlite3`. Если `DATABASE_PATH` не задан, бот автоматически
использует `DATA_DIR/kovcheg.sqlite3`, поэтому достаточно переменной
`DATA_DIR=/app/data`.

Если в `DATA_DIR` базы нет, а рядом с `bot.py` уже существует `kovcheg.sqlite3`,
бот использует найденную старую базу и не создаёт новую поверх прогресса.

Миграция больше не удаляет таблицы при изменении версии: существующие пользователи,
страны, партии и войны сохраняются. Но если запустить бота на сервере, где файла
`kovcheg.sqlite3` вообще нет, будет создана новая пустая база — это ожидаемо.

## Новые команды

- `/socialka`, `/ideologiya`, `/partii`, `/dvizhenie` — демография, качество жизни,
  одобрение власти, преступность, партии и локальные движения.
- `/naemniki`, `/naemnik_nanyat` — ЧВК с контрактом на 24 часа.
- `/soyuz_cel`, `/soyuz_vklad`, `/soyuz_nagrada` — общие цели союза и делёж награды.
- `/soyuz_rol`, `/soyuz_armiya`, `/soyuz_zapros` — роли и общая союзная армия.
- `/admin_dobavit_balans` — безопасное добавление кок администратором.
- `/admin_uroven` — установить уровень пользователя напрямую.
- `/admin_politika`, `/admin_vektor` — редактировать политические значения и вектор страны.
- `/admin_dobavit_predpriyatie` — добавить/установить уровень предприятия от 0 до 5.
- `/admin_naselenie`, `/admin_kazna` — установить население и казну страны.
- `/admin_resursy` — установить военные ресурсы, флот, верфи, генералов и укрепления.
- `/admin_user_stat` — изменить статистику пользователя: сообщения, голос, победы и гамбу.
- `/prodvinut_partiyu` — вложить кок в популярность партии.

При выборе страны `/vybrat` теперь обязательно указывается начальный политический
вектор. Партии создаются через `/dvizhenie` с одним из трёх векторов, получают
популярность и со временем могут как расти, так и терять поддержку. Вектор страны
можно сменить через `/ideologiya` только при наличии партии с нужным вектором и
поддержкой от 30%; смена снижает одобрение власти и имеет недельный период
ограничения. При достаточной популярности партия может стать правящей автоматически.

Discord ограничивает имена slash-команд латиницей, поэтому имена команд оставлены
в русской транслитерации, а описания, аргументы и ответы бота переведены на русский.

Одиночное нахождение в голосовом канале больше не начисляет голосовой опыт.
