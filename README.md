# Ковчег — обновлённая версия Discord-бота

## Запуск

1. Установить Python 3.10+ и зависимости:
   `pip install -r requirements.txt`
2. Задать переменную окружения `DISCORD_TOKEN`.
3. Запустить:
   `python bot.py`

При первом запуске или обновлении база SQLite мигрирует автоматически. Старый файл
`kovcheg.sqlite3` не удаляется.

## Новые команды

- `/socialka`, `/ideologiya`, `/partii`, `/dvizhenie` — демография, качество жизни,
  одобрение власти, преступность, партии и локальные движения.
- `/naemniki`, `/naemnik_nanyat` — ЧВК с контрактом на 24 часа.
- `/soyuz_cel`, `/soyuz_vklad`, `/soyuz_nagrada` — общие цели союза и делёж награды.
- `/soyuz_rol`, `/soyuz_armiya`, `/soyuz_zapros` — роли и общая союзная армия.
- `/admin_dobavit_balans` — безопасное добавление кок администратором.

Одиночное нахождение в голосовом канале больше не начисляет голосовой опыт.
